# 质检契约与限制

## 命令与退出码

```sh
python3 <skill>/scripts/video_audit.py film.mp4 --output qa --spec delivery-spec.json
python3 <skill>/scripts/video_audit.py film.mp4 --output qa --scan-seconds 60 --timeout 180
```

`--output` 是父目录，每次新建 UTC 时间戳＋随机标识的子目录。
不覆盖输入视频，不复用旧抽帧；报告包含输入 SHA-256、参数、工具版本、命令及日志。
命令超时是**每次子进程**的限制，不是整个制作任务总时间限制。
完整扫描默认处理首个非封面视频流和首个音轨；多流未检查部分会警告。
`--scan-seconds` 只缩短像素/音频异常扫描，完整帧时间轴索引仍读取全片。

| 退出码 | 含义 |
| --- | --- |
| 0 | 执行成功，完整机器检查、指定规格通过，无未解释异常候选 |
| 1 | 执行成功但有警告、规格失败、部分覆盖，或未给交付规格 |
| 2 | 参数/输入错误、工具缺失、超时、解码/抽帧等执行失败 |

`execution_status` 与 `technical_verdict` 分开。`0` **不表示**视觉、听觉、真实性或授权通过。
报告中的 manual_reviews 始终从 not_checked 开始，由真实复核另行记录证据。

## 交付规格

以 `templates/delivery-spec.json` 为结构示例，替换实际目标值。必须字段：
`width`、`height`、`fps`、`duration_s`、`audio`。
`audio` 可为 required / optional / forbidden。宽高指编码像素，旋转元数据会警告。
帧率同时核对平均帧率及（默认）实际帧间隔；可变帧率交付须显式 require_cfr=false。
未知字段拒绝，避免拼写错误悄悄失效。

可选数值界限：duration_tolerance_s、fps_tolerance、max_av_gap_s、max_true_peak_dbfs、
loudness_min_lufs、loudness_max_lufs。响度界限由项目确定，不内置伪装成平台官方规定的统一标准。
音频边界对齐不代表旁白口型或内容同步。静音情况下响度可能非有限，报告为 null＋警告。

## 异常候选与豁免

黑场阈值 0.20 秒、冻结 1.0 秒、静音 0.5 秒；启发式检测会漏检/误报，不是内容分类器。
片尾未闭合冻结/黑场按检查范围末端记录，并标 open_at_end。
允许事件必须完整覆盖被检测区间，写明理由，不能只与异常区间相交。
时间从所分析视频流或音轨的首个时间戳归零；非零音画偏移另行报告。

```json
{
  "allowed_events": [
    {"kind": "black", "start_s": 0, "end_s": 0.7, "reason": "已审：开头设计黑场"},
    {"kind": "freeze", "start_s": 23, "end_s": 25, "reason": "已审：片尾静态卡"}
  ]
}
```

以上仅展示片段，不能代替完整规格。不可为让检查变绿而自动批准未知异常。
允许事件不等于人工观看证据。全黑视频若被声明为黑场，也不会自动取得视觉验收。

## 抽帧与人工检查

按实际解码帧索引采样，涵盖真实首末帧，不使用容器时长减固定偏移找末帧。
可添加 key_times_s（最多18个）定位切镜、字幕和高风险时点，合计最多27张。
九宫格/拼图只是缩略图，不能验证完整时间连续性或逐帧闪烁；时间码在 JSON 中。
切镜、快速动作、细小文字、手机显示及配音需单独实际检查。

## 已知边界

- Python 内存中读取全片帧时间轴；以短视频为目标，超长素材可能耗时/内存较高。
- 缺少精确末帧时长时会估算并警告；不能声称精确容器对齐已验证。
- 不运行光学文字识别、不自动判断美感、不测量真实性或授权。
- 不测内容级音画同步，不代表所有音轨、字幕流或平台兼容性合格。
- FFmpeg 是外部依赖，建议在隔离环境处理不可信媒体；本工具不下载或安装它。
- 本地报告含媒体路径；公开前审查日志，勿上传私密素材/令牌或完整私人项目。
