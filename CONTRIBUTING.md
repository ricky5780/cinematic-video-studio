# Contributing

Keep the skill focused: director workflow and evidence-based checks, not another renderer.

Run `python3 -m unittest discover -s tests -v` with FFmpeg installed before proposing changes.
Use generated fixtures rather than copyrighted/client footage. Add regression coverage for fixed defects.
Keep README, SKILL.md, agents/openai.yaml, CLI behavior and exit-code documentation consistent.

Never turn incomplete review into pass. Distinguish machine measurement, static instruction checks and actual agent behavior tests.
Do not add automatic paid calls, publishing, global configuration changes or credential collection.
Contributions must be compatible with the MIT license; do not copy Lemo or another project's material without checking its license.
